# ❄️ Regin Sam's Fedora Hyprland Dotfiles

Welcome to my personal Hyprland configuration. This setup is built on **Fedora** and is a heavily customized version of the JaKooLit Hyprland repo, tuned for my specific workflow and aesthetic.

---

## ✨ Features
* **WM:** [Hyprland](https://hyprland.org/) (Dynamic Tiling Wayland Compositor)
* **Bar:** [Waybar](https://github.com/Alexays/Waybar) with custom CSS themes
* **Launcher:** Rofi-Wayland
* **Terminal:** Kitty
* **Shell:** ZSH with Oh-My-Zsh & Powerlevel10k icons
* **Notifications:** SwayNC
* **File Manager:** Dolphin

---
